# 💳 Трекер Подписок

Веб-приложение для управления подписками с адаптивным дизайном для мобильных устройств.

## ✨ Функционал

### Основные возможности:
- 📝 Управление подписками (добавление, редактирование, удаление)
- 🎨 Шаблоны популярных сервисов (ChatGPT, Claude, Midjourney, Netflix и др.)
- 💱 Автоматическая конвертация валют USD ↔ RUB (курс ~95₽)
- 📅 Календарь платежей с визуальными отметками
- 📊 Виджет статистики с аналитикой расходов
- ⚠️ Уведомления о предстоящих платежах (за 3 дня)
- 🔍 Сортировка и фильтрация подписок
- 📥 Экспорт данных в JSON
- 🌙 Темная тема
- 📱 Mobile-first дизайн

### Технологии:
- **Frontend:** React 18 + TypeScript
- **Сборка:** Vite
- **Стили:** Tailwind CSS v4
- **Хранение:** LocalStorage
- **Деплой:** Vercel

## 🚀 Запуск проекта

### Установка зависимостей
\`\`\`bash
npm install
\`\`\`

### Запуск в режиме разработки
\`\`\`bash
npm run dev
\`\`\`

### Сборка для production
\`\`\`bash
npm run build
\`\`\`

## 📁 Структура проекта

\`\`\`
src/

## 💡 Использование

1. Добавьте свою первую подписку, выбрав готовый шаблон или создав кастомную
2. Управляйте подписками: редактируйте, удаляйте, сортируйте
3. Отслеживайте статистику расходов в удобных виджетах
4. Используйте календарь для планирования платежей
5. Получайте уведомления о предстоящих списаниях
